# 🏦 Bank Marketing Data Analysis

## Overview
Analysis of bank marketing campaign data to predict 
customer subscription to term deposits.

## Dataset
- 41,188 records | 21 features
- Source: UCI Bank Marketing Dataset

## Tools Used
- Python, Pandas, Seaborn, Matplotlib
- Jupyter Notebook

## Key Findings
- 88.7% class imbalance (No vs Yes)
- Strong correlation between euribor3m & employment rate
- No missing values in dataset
